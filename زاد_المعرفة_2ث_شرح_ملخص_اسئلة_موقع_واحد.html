1) المفاهيم الأساسية

البرامج المجانية Freeware

برامج يسمح صاحب حق الملكية الفكرية باستخدامها دون مقابل مادي، مع بقاء حقوق الملكية لصاحبها.

البرامج مفتوحة المصدر Open Source

برامج منشورة تسمح للمستخدمين بالاطلاع على الكود وإمكانية تعديله وتطويره وفق الاحتياجات ثم استخدام النسخة المعدلة.

صفحة الويب الساكنة Static Web Page

صفحة تعرض معلومات من خلال مستعرض الإنترنت، وتحفظ غالبًا بامتداد .htm أو .html. تعرض نصوصًا وصورًا وفيديو وجداول وروابط، ولا تجري معالجة لمحتوى الصفحة على الخادم.

صفحة الويب الديناميكية Dynamic Web Page

صفحة يمكن أن تتضمن معالجة للمحتوى، مثل قراءة مدخلات المستخدم أو التعامل مع قاعدة بيانات. يوضح الكتاب أمثلة باستخدام PHP وASP.NET ويكون جزء من المعالجة على جهاز الخادم.

مفتاح سريع: Static = عرض محتوى ثابت غالبًا. Dynamic = معالجة ونتائج متغيرة وفق البيانات أو المستخدم.

الخادم Server

يستخدم المصطلح بمعنيين: جهاز بمواصفات مناسبة داخل الشبكة، أو دور/خدمة يؤديها جهاز داخل الشبكة. ومن الأمثلة: Web Server وPrint Server وMail Server وDatabase Server.

Script وHTML وPHP

Script كود يؤدي مهمة أو معالجة. HTML لغة ترميز لإنشاء صفحات ويب ساكنة. PHP لغة تعمل جهة الخادم وتستخدم في تطوير صفحات ديناميكية ويمكنها التعامل مع قواعد البيانات.

2) أدوات تشغيل ونشر الموقع

Apache Server

يستخدم لمحاكاة دور الخادم على الكمبيوتر الشخصي وتشغيل/ترجمة كود PHP محليًا قبل نشر الموقع على الإنترنت.

طرق النشر

يمكن عرض الموقع محليًا على Localhost داخل الجهاز أو الشبكة المحلية، أو رفعه إلى جهاز استضافة Web Hosting ليصبح متاحًا عبر عنوان URL.

SQL

لغة تستخدم لإدارة قواعد البيانات والتعامل معها. يذكر الكتاب أوامر أساسية: INSERT للإضافة، SELECT للاستعراض، UPDATE للتعديل، DELETE للحذف.

MySQL Server

نظام إدارة قواعد بيانات علائقية RDBMS.

Session

طريقة لتخزين معلومات عن زائر الموقع لتظل متاحة عبر صفحات الموقع، مثل اسم المستخدم وبعض بيانات الجلسة.

3) تخطيط مشروع قاموس المصطلحات

هدف المشروع إنشاء موقع قاموس مصطلحات مصور باستخدام أدوات ولغات مجانية ومفتوحة المصدر. تشمل المهام: تهيئة البيئة، إنشاء قاعدة البيانات، تصميم الصفحة الرئيسة، إضافة مصطلح، البحث، الحذف، التعديل، وتوفير المساعدة.

يؤكد الكتاب على وضع جميع ملفات الموقع في مجلد واحد مع مجلدات فرعية للأنواع المختلفة، واختيار أسماء ملفات مختصرة ومعبرة وباللغة الإنجليزية.

يمر التنفيذ بثلاث مراحل عامة: إنشاء قاعدة بيانات، إنشاء صفحات ويب ساكنة، ثم تحويل الصفحات اللازمة إلى صفحات ديناميكية بإضافة PHP والتعامل مع قاعدة البيانات.

الوحدة الثانية: متطلبات ومراحل إنتاج المشروع

تصميم الصفحات، إنشاء جداول قاعدة البيانات، ثم الانتقال إلى بناء صفحات الموقع.

4) تصميم صفحات الموقع

من الصفحات التي يحددها الكتاب للمشروع: الصفحة الرئيسة، إدخال مصطلح، البحث عن مصطلح، تعديل مصطلح، حذف مصطلح، المساعدة، بالإضافة إلى صفحات مساعدة مثل الاتصال بقاعدة البيانات وHeader.

  • Index.php: واجهة الموقع.
  • Add_term.php: إضافة مصطلح.
  • Search_term.php: البحث وعرض البيانات.
  • Edit_term.php: تعديل بيانات مصطلح.
  • Del_term.php: حذف مصطلح.
  • Help.php: المساعدة والمعلومات.
  • Connection.php: فتح الاتصال بقاعدة البيانات.
  • Header.php: الصورة العلوية والروابط المشتركة.
فصل العناصر المشتركة في صفحات مستقلة يقلل تكرار الكود في جميع صفحات الموقع.

5) قواعد البيانات: المفاهيم الأساسية

Database

مجموعة بيانات منظمة ومرتبطة بموضوع معين، تُخزن بهدف استرجاعها والاستفادة منها.

Table / Record / Field

الجدول يتكون من سجلات وحقول. السجل Record صف يجمع بيانات حالة أو شخص واحد. الحقل Field عمود يمثل نوعًا محددًا من البيانات.

من خصائص الحقل: الاسم، نوع البيانات مثل String أو Numeric أو Date، والحجم Size.

Primary Key

حقل لا تتكرر قيمته ويستخدم لتمييز كل سجل. إذا لم يوجد حقل طبيعي مناسب يمكن إضافة حقل جديد مثل «رقم الطالب».

أنواع العلاقات

العلاقةالفكرةمثال الكتاب
One to Oneسجل يقابله سجل واحدبيانات الطالب ↔ حالة الطالب
One to Manyسجل واحد يقابله عدة سجلاتالصف ↔ الطلاب
Many to Manyعدة سجلات تقابل عدة سجلاتالصفوف ↔ المعلمون

العلاقة Many-to-Many تُحل عمليًا بجدول ربط، ويتكون مفتاحه الأساسي المركب من مفتاحي الجدولين المشاركين.

كائنات نظم إدارة قواعد البيانات

يذكر الكتاب الجداول Tables والاستعلامات Queries كأمثلة أساسية.

6) قاعدة بيانات المشروع

اسم قاعدة البيانات في المشروع: dbdictionary، ويستخدم جدولًا باسم Terms. الكتاب يجعل المشروع بجدول واحد للتبسيط.

المشروع التدريبي يستخدم MySQL لإدارة قاعدة البيانات.

الوحدة الثالثة: إنشاء صفحات موقع قاموس مصطلحات الكمبيوتر المصور

HTML وPHP، إعداد الملفات، التعامل مع قاعدة البيانات، المعاملات والجمل الشرطية، ثم صفحة إضافة مصطلح.

7) لغة HTML

HTML لغة ترميز لإنشاء صفحة ويب، ويمكن كتابة الكود في محرر نصوص وحفظ الملف بامتداد .htm أو .html.

<html> <head> <title>عنوان الصفحة</title> </head> <body> محتوى الصفحة </body> </html>
  • الأوامر Tags توضع بين < >.
  • معظم Tags لها بداية ونهاية.
  • HEAD لمعلومات رأس الصفحة، وTITLE لعنوان النافذة، وBODY للمحتوى المرئي.

8) أساسيات PHP

كود PHP يكتب بين علامتي البداية والنهاية، وينفذ جهة الخادم.

<?php $name = "Mohamed"; echo "my name is $name"; ?>

المتغيرات

اسم المتغير يبدأ بعلامة $. يتعرف PHP على نوع المتغير من القيمة المسندة إليه. من الأنواع المذكورة: String وInteger وDouble وBoolean.

الثوابت

define('name','Mohamed'); echo 'my name is: '.name;

التعليقات

يذكر الكتاب // للتعليق القصير، والتعليق الممتد بين العلامات المخصصة له.

9) الاتصال بقاعدة البيانات

يوضح الكتاب أن الاتصال يحتاج أربعة بيانات أساسية: اسم الخادم، اسم المستخدم، كلمة المرور، واسم قاعدة البيانات.

العنصرقيمة المثال في الكتاب
اسم الخادمlocalhost
اسم المستخدمroot
كلمة المرورفارغة في المثال التعليمي
قاعدة البياناتdbdictionary
الكود المعروض في الكتاب يستخدم دوال MySQL تعليمية قديمة؛ الملزمة هنا تشرح ما ورد في الكتاب كما هو دون استبداله بمكتبات أحدث.

10) المعاملات والجمل الشرطية في PHP

المعاملات الحسابية

+ ، - ، * ، / ، %، وكذلك صور مختصرة مثل += و-= و*= و/= و%=، والزيادة ++ والنقص --.

المقارنة

== ، != ، > ، >= ، < ، <=

المعاملات المنطقية

OR يرمز لها ||، وAND يرمز لها &&، وNOT يرمز لها !.

If / Elseif / Else

if ($x > 0) { echo "الرقم موجب"; } elseif ($x < 0) { echo "الرقم سالب"; } else { echo "الرقم يساوي صفر"; }

Switch

تستخدم لاختبار عدة احتمالات لقيمة واحدة، مع حالات case وحالة default.

11) صفحة Add_Term.php

الصفحة مصممة لإدخال بيانات مصطلح جديد. يستخدم النموذج Form لإرسال البيانات إلى الخادم، ويعرض الكتاب الفرق بين GET وPOST.

GETPOST
تظهر البيانات في عنوان URLلا تظهر البيانات المرسلة في عنوان URL
لا يناسب البيانات المهمة وفق شرح الكتابيستخدم مع البيانات المهمة مثل كلمات السر وفق شرح الكتاب

تتضمن خطوات الإضافة: تضمين Header وConnection، التحقق من الضغط على زر الإضافة، قراءة قيم النموذج، التعامل مع ملف الصورة، ثم تنفيذ أمر إدخال البيانات والتحقق من نجاح العملية.

فكرة الكود الأكثر دقة في الكتاب: التأكد من وجود مجلد الصور، التحقق من اختيار ملف، التحقق من عدم ترك الحقول فارغة، ثم عرض رسالة نجاح أو رسالة توضح وجود مشكلة.

الوحدة الثالثة: HTML + PHP

HTML للحفظ

الكود يبدأ بـ HTML وينتهي به، وHEAD لمعلومات الرأس، وTITLE للعنوان، وBODY للمحتوى. تحفظ الملفات بامتداد .htm أو .html.

<html><head><title>Title</title></head><body>Content</body></html>

PHP للحفظ

  • اسم المتغير يبدأ بـ $.
  • = تخصيص قيمة، بينما == مقارنة.
  • Echo أو Print للطباعة.
  • الأنواع المذكورة: String / Integer / Double / Boolean.
  • الثابت يُعرّف باستخدام define.
  • كل جملة PHP تنتهي بفاصلة منقوطة.

المعاملات والشروط

حسابية: + - * / %   |   مقارنة: == != > >= < <=   |   منطقية: || و && و !

If لشرط أو أكثر، وSwitch مناسب لعدة احتمالات لقيمة واحدة.

GET وPOST

GET: البيانات تظهر في URL. POST: البيانات لا تظهر في URL. ووفق الكتاب يستخدم POST عند إرسال بيانات مهمة.

س32) متى نستخدم If؟

لاختبار شرط وتنفيذ كود بناءً على صحة الشرط أو عدمه.

س33) متى تكون Switch مناسبة؟

عند اختبار عدة احتمالات لقيمة واحدة.

س34) اذكر بيانات الاتصال الأربعة بقاعدة البيانات.

اسم الخادم، اسم المستخدم، كلمة المرور، اسم قاعدة البيانات.

س35) ما قيم المثال التعليمي للخادم والمستخدم وقاعدة البيانات؟

localhost وroot وdbdictionary.

س36) ما الفرق بين GET وPOST حسب الجدول في الكتاب؟

GET تظهر بياناته في URL، وPOST لا تظهر بياناته في URL.

س37) ما الخطوات الأساسية عند إضافة مصطلح؟

تضمين Header وConnection، قراءة بيانات النموذج، التحقق من القيم والملف، إدخال السجل، ثم إظهار نتيجة العملية.

س38) لماذا يفحص الكود وجود مجلد الصور؟

حتى ينشئه عند عدم وجوده قبل حفظ ملف الصورة.

س39) ماذا يحدث في النسخة الأدق من الكود إذا كانت بعض الحقول فارغة؟

يعرض رسالة تفيد أن البيانات غير صحيحة ويطلب إدخال جميع الحقول.
